# メニュー写真の追加・差し替え

`src/data/menu-images.json` が全22品の写真設定です。メニュー名・価格・並び順・初期開閉は `index.html` にあります。

1. 写真を `public/menu/` に置きます。推奨は横4:3・横幅1200px程度のWebPです。
2. 該当するキーの `src` を `/menu/ファイル名.webp` に設定します。
3. `alt` に写真の説明、`caption` に必要な出典やイメージ表記を記載します。
4. `npm run check`、`npm run build` で確認後に公開します。

例：`food-oyster` はカキフライ定食です。

```json
"food-oyster": {
  "src": "/menu/oyster.webp",
  "alt": "カキフライ定食の写真",
  "caption": ""
}
```

`src` が空欄の場合は「写真は準備中です。」を表示します。画像の読込に失敗した場合も同じ表示へ戻り、壊れた画像を残しません。開閉機能自体は画像未設定でも利用できます。

各カテゴリの先頭は初期表示時に開きます。同一カテゴリでは一品ずつ開く構成です。カテゴリ変更後は利用者が開閉した状態を保持します。ネイティブの `details` / `summary` を使い、タップ・Enter・Spaceで操作できます。
