# madomado mascot — visual target v2 / 静止画の品質検証

## 今回の到達点

旧Blender試作の微修正をやめ、元イラストから新しい3D調の造形見本を生成した。
その見本を同一人物・同一衣装の基準にして、閉眼とウインクの静止差分を制作した。
ユーザーの「無料の範囲」「画像を組み合わせた表情演出も可」という追加指示に従い、有料3D復元の再試行は行っていない。

**これは高品質な3D調の生成画像であり、Blender等でレンダリングした実メッシュの証明ではない。新しいGLB / .blendは未作成。**

- `sculpt-target.png`：基準。開眼した歓迎の笑顔。1276×1233。
- `expression-eyes-closed.png`：両目を閉じた柔らかな笑顔。1277×1232。

## 総合評価

| 観点 | 評価と残る差 |
| --- | --- |
| 顔の造形 | 頬・鼻・口元・額が自然につながり、旧試作の部品を組み合わせた印象が改善。原画の丸い頭と大きな耳を維持。ただし原画より犬らしいマズルと立体的な眉に翻案している。 |
| 毛並み | 毛流れ、頬のボリューム、耳縁の細い毛、手の柔らかさが読み取れる。原画の黄色を保った暖かな表現。ただしすべて画像上の表現であり、編集可能な3Dグルームではない。 |
| 目 | 虹彩の繊維、瞳孔、角膜の反射があり、旧試作の金属／ゴーグルのような印象を改善。閉眼では瞳とハイライトが残らない。原画より虹彩の茶色が明瞭。 |
| 革ジャン | 襟の折り返し、肩と腕の皺、ステッチ、金具、骨パッチに素材の説得力がある。衣装のボリュームも柔らかい。ただし原画の単純化された装飾を細部へ翻案している。 |
| 表情・愛嬌 | 丸い目、口角、小さな舌、柔らかな頬を共有。開眼・閉眼・ウインクでキャラクターの印象をおおむね保てている。静止ビジュアルの方向として採用候補にできる。 |
| 実3Dの完成度 | 未評価。メッシュ、裏側、UV、毛の実装、照明変更や斜め視点への耐性を検証できるデータはない。映画・ゲーム用3Dアセットが完成したとは扱わない。 |

結論：**原画の魅力を高品質な静止ビジュアルへ翻案する方向は改善した。無料範囲での画像ベース表情演出の素材候補として保存。実3Dモデルの完成・アニメーション素材の完成とは区別する。**

## 将来、画像ベースで表情を動かすなら

1. 開眼画像を唯一の固定ベースにする。
2. 差分画像を位置合わせし、目元だけをマスクして重ねる。
3. 耳・髪・輪郭・口・手・服・背景は固定ベースを維持する。
4. 全画像のクロスフェードでは、毛並み・縫い目・金具が微妙に揺れて見えるため避ける。
5. 閉眼差分は寸法にも1px程度の差がある。基準画像とピクセル単位で一致したフレームではない。
6. この工程では位置合わせ、マスク素材作成、時間軸アニメーション、Web組み込みは行っていない。
